# 多文档对照 · MultiDoc Reader

一个本地 Chrome 扩展，在全屏窗口中并排阅读多份飞书原文档，支持统一查找、各栏独立查找、统一切换匹配结果、联动滚动及阅读缩放。当前版本 **0.1.1**，仍为待真实页面验收的原型。

## 先配置自己的飞书站点

公开源码使用示例站点 `example.feishu.cn`，不包含真实组织域名、文档地址或登录信息。安装前，将以下文件中的示例主机名替换为你获准使用的飞书主机名：

- `extension/core.mjs`：链接校验与工作台的站点来源。
- `extension/reader.js`：正文控制脚本的来源校验。
- `extension/manifest.json`：可选站点权限及 iframe 内容安全策略。
- `extension/controller.html`：链接输入提示。
- `tools/package.py`：安装说明。
- `tests/`：合成测试地址；`reader.test.mjs` 中还包含转义后的域名正则表达式。

上述位置必须保持一致。仅配置确切主机名，不要扩大为通配所有网站。配置改变权限后，应重新核验权限并重新加载扩展；测试通过不能替代真实文档检查。

## 安装与使用

1. 打开 Chrome 扩展管理页面，开启开发者模式，选择“加载已解压的扩展程序”，选中已配置的 `extension/` 目录。
2. 点击扩展图标，打开全屏工作台；点击“＋ 文档”，每行粘贴一份 wiki/docx 文档链接，并在需要时授予指定飞书站点访问权限。
3. 顶部搜索框让勾选的文档一起定位；顶部“上一处／下一处”统一切换重复匹配。各栏搜索及箭头可以独立使用，在文档内按 ⌘F / Ctrl+F 展开本栏搜索。
4. 通过“联动滚动”开关切换独立阅读和跟随；`A− / 百分比 / A+` 调整 80%～150% 的阅读大小，点击百分比恢复默认。文字、图片和表格同比缩放。
5. 可收起顶部工具条专注阅读；扩展重新加载或浏览器关闭后，本次文档清单会清空。

文档数量不固定，超出窗口宽度时横向展开。保留飞书原文、图片、表格、评论入口、水印及访问控制。不能绕过组织的登录、分享或嵌入限制。

## 权限与数据

- 扩展权限为 `scripting`、`storage`，以及连接时申请的指定飞书站点权限。没有 Cookie、调试器或浏览历史权限。
- 主机权限在技术上覆盖指定站点。动态脚本只匹配 wiki/docx 路径，并要求直接父框架为本扩展；工作台还检查扩展、标签页、子框架及已添加文档身份。
- 会话存储只保存文档链接、标题、勾选状态、阅读大小和窗口标识，不保存正文、密码或凭据。滚动对齐最多通过本机扩展消息传递三段正文片段，仅在内存中使用。
- 扩展没有上传正文、远程脚本、模型调用或第三方依赖，不开公网端口。飞书原页面仍使用已有登录状态正常请求文档、图片和飞书资源。
- 可在 Chrome 中撤销站点访问、停用或移除扩展，停止运行。添加、移除栏目不会修改原文档。

## 验证与限制

使用 Node.js 22 和 Python 3，无需安装项目依赖：

```sh
node --test tests/*.test.mjs
node --check extension/controller.mjs
node --check extension/core.mjs
node --check extension/reader.js
node --check extension/background.js
python3 tools/package.py
```

打包脚本生成顶层包含 `manifest.json` 的 ZIP，并检查运行文件和图标的一致性；遇到安装目录中被手动改动的文件会停止覆盖。安装输出目录沿用历史名称，版本应以 manifest 和界面中的 `v0.1.1` 为准。

33 项本地自动检查覆盖链接边界、消息身份、搜索、统一导航、独立搜索、缩放及三栏滚动消息链路，使用合成页面和模拟 Chrome 接口。**最新版本尚未完成真实 Chrome 扩展页面验收，不能据此认定联动滚动故障已消失。**

搜索是字面匹配，滚动优先对齐已渲染的相同正文片段，缺少共同片段时回退为相对阅读进度；不同排版、图片高度和飞书虚拟渲染可能产生偏差，不保证逐句对齐。飞书页面结构更新可能影响查找与定位。大量文档、长期运行、评论交互和帧率尚未全面验证。

公开仓库不附带真实文档、内部验收记录、浏览器配置、截图、凭据或个人本机路径。
